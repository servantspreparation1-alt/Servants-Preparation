🔑 أداة إدارة الحسابات في قاعدة البيانات

تغيّر اسم المستخدم وكلمة السر مباشرة في Firebase — بدون ما تعرف الـ hash

1) رابط قاعدة البيانات

كلمة السر في القاعدة مخزّنة كـ hash بالمعادلة: sha256( username.toLowerCase() + "::" + password )
يعني مستحيل تكتب كلمة السر نفسها في Firebase — لازم الأداة دي تحسب الـ hash وتكتبه.
مثال: lucaskayser + Fady2026L = …

2) الحسابات الموجودة

اضغط «اقرأ الحسابات» الأول.

3) تعديل / إنشاء حساب

4) آخر العمليات

لسه مفيش عمليات.
